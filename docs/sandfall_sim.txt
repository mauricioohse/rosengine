Building a sandfall simulator using rosengine

it will be a small scale basic sand-pixel-material simulator

general idea:
    - physics simulation that acts on every pixel and certain things happen for each material in certain conditions
    - user can input using mouse to place selected material
    - selected material is selecter by choosing a box with the material in the top
    - user can also save the current game into a file and load it later
    - materials:

    air:
        - default material

    sand:
        - affected by gravity
        - when too hot, turns into glass

    fire:
        - can only exist where air existed before
        - generate smoke when cools off
        - heats up adjacent tiles
